# stephendossou.github.io

Personal academic website of Stephen Dossou (PhD candidate in Economics, Mines Paris – PSL, CERNA).

Static site served by GitHub Pages. `index.html` is self-contained (inline CSS/JS, no build step).

## Structure
- `index.html` — homepage
- `cv.pdf` — curriculum vitæ
- `papers/` — working papers and job market paper (PDF)
- `build/mfn/` — LaTeX source for the section-6-free version of the bridge-financing model

## Publishing
Push to a repository named `stephendossou.github.io`, then enable
Settings → Pages → Deploy from branch → `main` / root. The site goes live at
https://stephendossou.github.io
